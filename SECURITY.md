# Security Policy

## Supported Versions

Smarty currently supports the latest minor version of Smarty 4 and Smarty 5.

| Version | Supported          |
|---------|--------------------|
| 5.x.y   | :white_check_mark: |
| 4.x.y   | :white_check_mark: |
| < 4.x.y | :x:                |

## Reporting a Vulnerability

If you have discovered a security issue with Smarty, please open a [new security advisory](https://github.com/smarty-php/smarty/security/advisories/new).
Do not disclose your findings publicly and **PLEASE** do not file an Issue (because that would disclose your findings publicly.)
 
We will try to confirm the vulnerability and develop a fix if appropriate. When we release the fix, we will publish 
a security release. Please let us know if you want to be credited.
