- Fixed the `raw` modifier (and `escape:'url'`, `'javascript'` etc.) disabling auto-escaping for the whole printed value when applied to only a part of it, e.g. `{$foo|cat:($bar|raw)}` or `{$x ? ($bar|raw) : $foo}` output `$foo` unescaped. Such values are now escaped as a whole; use `{$foo|cat:$bar|raw}` to output the combined value raw [#1215](https://github.com/smarty-php/smarty/issues/1215)
